Blyri.X is a dedicated local music player built strictly for the audio files already stored on your phone. It does not download music from any online sources, and works offline without accounts, subscriptions, or ads.

> [!NOTE]
> This repository hosts the official information page for Blyri.X. Official releases and automatic updates are distributed exclusively through the [Google Play Store](https://play.google.com/store/apps/details?id=com.linermusicplayer.app). The current store release is **v1.3.8**, with **v1.3.9** coming soon.

## Features

> [!TIP]
> Most of the newer additions listed below (such as Play Next and Up Next queue management, Sleep Timer, Android Auto support, additional light themes, and custom cover controls) are part of **v1.3.9** coming soon to Google Play.

| Area | What Blyri.X Offers |
| :--- | :--- |
| **Music Library and Queue** | Fast local scanning, instant search, sorting, Playlists, Custom Albums, and multiple selection tools. Upcoming in `v1.3.9`: Play Next, Add to Queue, and an Up Next manager to reorder or clear upcoming songs. |
| **Synchronized Lyrics** | Time synced lyrics that follow playback, tap any line to jump straight to that timestamp, paste text or LRC lyrics, or save lyrics directly into audio file tags. Includes Focus mode for a large cover player without lyrics. |
| **Cover Art Management** | Automatic missing cover lookup, cover editor in Settings, and a 7 day backup to restore previous covers. Upcoming in `v1.3.9`: Custom Cover picker right inside each song menu and custom cover protection during library refreshes. |
| **Audio Tuning and Sleep Timer** | Graphic Equalizer with presets and custom bands, plus optional silence skipping. Upcoming in `v1.3.9`: Sleep Timer supporting quick presets, custom minutes, or stopping at the end of the current track. |
| **Android Auto** | Coming in `v1.3.9`: Browse Songs, Albums, and Artists, run voice or text searches, and control playback cleanly from your car display. |
| **Local WiFi Transfer and Care** | Share music, playlists, lyrics, and settings between devices on the same local WiFi network with no cloud servers, clean up duplicate tracks, and hide unwanted folders or recordings without deleting files. |
| **Themes** | Dark and light palettes, automatic phone theme matching, and dynamic accent colors sampled from the playing album art, with expanded light themes arriving in `v1.3.9`. |
